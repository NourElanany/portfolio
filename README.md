# بورتفوليو نور الدين أسامه فتحي العناني
## مهندس رؤية حاسوبية وذكاء اصطناعي (Computer Vision & AI Engineer)

### التشغيل المحلي:
```bash
npm install
npm run dev
```

### البناء للنشر (Production Build):
```bash
npm run build
```

### النشر المباشر على Vercel:
1. ارفع المشروع على حسابك في GitHub.
2. ادخل على vercel.com واضغط "Add New Project" واختر المستودع.
3. اضغط "Deploy" وسيتم البناء والنشر فوراً في أقل من دقيقة!
